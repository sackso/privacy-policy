Privacy Policy for 부가세 공제/불공제 도우미

Last updated: September 13, 2026

This Privacy Policy describes how 부가세 공제/불공제 도우미 ("the Extension") handles user information and data privacy.

1. Data Collection and Usage

The Extension does not collect, store, or transmit any personally identifiable information (PII), sensitive personal data, financial information, or browsing history to external servers.

To verify the license state (PRO/FREE version status), the Extension generates an anonymous unique identifier (User ID). This User ID is stored locally on the user's browser using chrome.storage.local and is used solely to query activation status.

2. Third-Party Services

All payment processing and form submissions are handled externally through secure third-party platforms (such as Google Forms and Toss Payments). The Extension itself does not handle, store, or process any payment credentials or personal financial data.

3. Data Security

Because no personal data is collected or transmitted outside the local browser environment by the Extension, your data remains safe and secure on your local device.

4. Permissions Justification

  • storage: Used strictly to save the local activation state and anonymous User ID on your device.
  • activeTab: Used only when explicitly invoked by the user to interact with the active tab for VAT classification assistance.
